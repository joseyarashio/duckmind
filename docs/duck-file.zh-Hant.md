# 小鴨檔案：一隻小鴨＝一個檔案

[English](duck-file.md)

在模擬器裡養的小鴨，住在電腦上的一個資料夾（牠的「生命資料夾」）。**小鴨檔案**把讓牠成為牠的東西
打包成一個檔案，搬到另一台電腦，牠還是同一隻：同樣的名字和個性、同樣的成長日、階段和方向、認得同樣的人、
會同樣的把戲而且一樣熟練、叫聲也一樣。

**家不會跟著走**。家的地圖、家具、牠記得的地方和窩的位置都留在原地：到了新家（或換了新身體），
牠要重新認識環境，真的寵物也是這樣。

## 怎麼用

**在頁面上**：打開「換鴨子」分頁，「我的小鴨檔案」卡片有兩個鍵：

* **匯出小鴨檔案**：下載這台模擬器養的小鴨，檔名是 `<名字>-<日期>.duck`。會先存一次牠的心，
  所以檔案就是牠現在的樣子。（只有用 `--life 資料夾` 啟動的模擬器才有這個鍵。）
* **匯入小鴨檔案**：選一個 `.duck` 檔。頁面會先檢查，告訴你裡面是誰（名字、成長第幾天、認得幾個人、
  練過幾個把戲）。按 **放進這台電腦**，就幫牠做一個新的生命資料夾。之後用那個資料夾啟動模擬器
  （`--life 資料夾`），就是同一隻小鴨。

**用指令**：

```
python -m duckmind.life.duckfile export 生命資料夾 [-o 檔案.duck] [--no-voice]
python -m duckmind.life.duckfile inspect 檔案.duck
python -m duckmind.life.duckfile import 檔案.duck [--into 新資料夾] [--replace]
```

`import` 會在 `<DUCKMIND_HOME>/lives/`（預設 `~/.duckmind/lives/`）做一個用小鴨名字命名的新資料夾。
匯出時，最好沒有伺服器正在養這隻小鴨，或用頁面上的鍵：頁面會先存牠的心，指令則照硬碟上的檔案讀。

## 檔案裡有什麼

小鴨檔案是一個 zip：

| 內容 | 放了什麼 |
|---|---|
| `manifest.json` | 格式 `duckmind.duckfile`、版本、做的時間、哪一版程式做的、小鴨的數字（代號、名字、種子、出生、天性、成長日、階段、方向、認得幾個人、每個把戲的熟練度）、叫聲庫、留下了什麼，以及其他每一份的 SHA-256 檢查碼和大小 |
| `duck/life.json` | 生命紀錄：名字、種子、出生、天性、孵化時的硬體 |
| `duck/core.json` | Duck Core 的存檔：完整的成長紀錄、每一筆輸入，一個位元組都不改 |
| `duck/neural.json` | 神經鴨學到的東西：認得的人（家人取的名字和長相）、線索、把戲本、習慣和驅力；**不含**地方、東西、窩的位置和地圖 |
| `voice/<key>/…` | 牠現在的叫聲系譜聲音庫：學會的叫聲（wav 片段）和它們的計畫 |

故意不放的：家的地圖和家具（地方、東西、窩的位置、長久的地圖）、眼睛記得的某個家的地板（`eye/`）、
版面編輯器套用過的版面（`layouts/`）、上一份心智快照，還有小鴨這個物種的聲音庫（另一台電腦會照牠的種子
重新產生）。一個小鴨檔案大約 1–2 MB。

**牠是誰**：小鴨的代號由牠的種子和出生的那一刻算出來。同一個種子、不同時間孵化的是兩隻不同的小鴨；
同一隻小鴨的每一份複本代號都一樣。

**叫聲**：聲音庫用叫聲系譜算出來的鑰匙命名，同樣的系譜就是同樣的鑰匙、同樣的聲音。檔案裡帶著這些聲音，
匯入時放到伺服器會去找的地方，另一台電腦的伺服器就直接用。之後牠長大、聲音變了，新的聲音庫會用那台電腦
自己的聲音庫做。

## 安全規則

* **絕不悄悄蓋掉**：匯入一定做新的生命資料夾。如果這台電腦已經有同一隻小鴨（代號一樣），除非你要求取代
  （`--replace`，或頁面上的 **取代（先留備份）**），否則不收；被取代的資料夾會先改名留著，叫
  `<資料夾>.replaced-<時間>`。正在模擬器上活著的那隻小鴨絕不取代。資料夾名稱被別的東西用了，就換一個名字，
  什麼都不蓋過去。
* **寫進去之前先檢查**：每一份都要和說明裡的檢查碼與大小一致，而且不能多出別的東西。比較新的程式做的檔案
  （小鴨檔案、生命紀錄或快照的版本比較新）不收；比較舊的版本會照升級步驟讀。Duck Core 的存檔必須能在這版
  程式上重播：在另一版成長引擎上長大的小鴨，這版不能接著養。各部分必須是同一隻小鴨的。
* **私密**：檔案裡有人的名字和長相（是一串數字，不是照片）。用指令匯出的檔案只有你自己能讀（從頁面下載的檔案由瀏覽器存），
  程式絕不把它送到任何地方，模擬器的匯出和匯入只回應同一台電腦上的瀏覽器。檢查碼能發現檔案壞掉或不小心被改，
  但不是簽章，所以只匯入你自己做的或信得過的檔案。
