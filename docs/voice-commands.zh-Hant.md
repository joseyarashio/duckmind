# 用說的下指令（按住說話）

English: [voice-commands.md](voice-commands.md)

模擬器頁面的指令框旁邊有一個「說話」按鈕（🎤）。按住它，對小鴨說一句指令，再放開。頁面會寫出聽到什麼、懂成什麼，例如「聽到：「坐下」→ 坐下」，小鴨收到的指令跟你打字送出的一模一樣。要不要照做，還是牠自己決定。

**全部在你的電腦上做。** 頁面只在你按住按鈕的時候錄音，錄好的聲音只送到同一台電腦上的 duckmind 伺服器。伺服器用本機的 Whisper 模型把聲音變成字，聲音只放在記憶體裡辨識這一次，不寫進硬碟，也不送到任何雲端服務。請看 [PRIVACY.md](../PRIVACY.md)。

## 怎麼打開

1. 裝語音套件：`pip install 'duckmind[voice]'`（或 `uv sync --extra voice`）。Apple 晶片的 Mac 用 [mlx-whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper)（MIT），它會連 PyTorch 一起裝（檔案很大）；其他電腦用 CPU 跑的 [faster-whisper](https://github.com/SYSTRAN/faster-whisper)（MIT）。[pypinyin](https://github.com/mozillazg/python-pinyin)（MIT）用來比對中文裡聽起來很像的字。
2. 用神經小鴨（`--brain neuro`）啟動模擬器。語音指令預設就是開的（`--voice-commands auto`）。第一次啟動會從 Hugging Face 下載一次模型（Whisper medium，約 1.5 GB），之後不用網路也能用。
3. 用 `http://localhost:<埠號>` 打開頁面（瀏覽器只在 `localhost` 或 HTTPS 才准用麥克風）。第一次按會問你能不能用麥克風。

`--voice-commands off` 關掉；`--voice-commands mlx:<模型>` 或 `faster:<模型>` 換別的 Whisper 模型。

## 可以說什麼

頁面用哪種語言，就聽哪種語言（繁體中文、English、日本語、Español、简体中文、한국어）。

- **指令**：跟指令框一樣的字：坐下、站起來、過來、看我、停、跟著我、回家，還有把戲（趴下、轉圈、鞠躬、甩一甩、翻跟斗）。前面可以加小鴨的名字（「蛋黃，坐下」）。
- **稱讚和罵**：「乖」「好棒」是稱讚，「不對」「不是這樣」是罵，跟回饋按鈕一樣。
- **其他的話**什麼都不會發生，頁面會說那不是指令。

按一次說一句短的，最長 10 秒。按得太短、或是按了沒說話，根本不會送去辨識。

辨識寫出的字如果只是「聽起來像」指令（「按我」其實是「看我」），伺服器會拿整句的發音跟指令詞比，取最像的那個，但只在它明顯最像的時候。一句比較長的話裡剛好有像指令的音，不算。

## 準不準

用 450 句固定的測試句（每種語言 75 句）量，由本機的語音合成用四個虛構的聲音念出來，在任何真人的聲音試過之前就定好。數字是每種語言 70 句指令／稱讚／罵裡答對的比例，以及 5 句不是對小鴨說的話裡，有幾句還是讓牠動了。

| | 繁中 | English | 日本語 | Español | 简中 | 한국어 |
|---|---|---|---|---|---|---|
| 安靜的房間 | 82.9 % | 100 % | 95.7 % | 91.4 % | 91.4 % | 95.7 % |
| 家裡的噪音，10 dB | 81.4 % | 100 % | 91.4 % | 92.9 % | 87.1 % | 98.6 % |
| 家裡的噪音，5 dB | 80.0 % | 100 % | 92.9 % | 92.9 % | 84.3 % | 95.7 % |
| 不是對小鴨說的，還是動了 | 0 / 5 | 0 / 5 | 1 / 5 | 0 / 5 | 0 / 5 | 0 / 5 |

Apple 晶片（M5 Pro）上的 Whisper medium；噪音是 DEMAND 資料集的客廳、廚房、洗衣房錄音。繁中最弱：兩三個字的指令單獨說，常被聽成別的字（有一部分是合成的聲音本來就念得不清楚）。合成的聲音不是真人的聲音，你自己的結果會不一樣。

**多快。** 從放開按鈕到小鴨收到指令，在跑著的模擬器上量（M5 Pro，同時有別的模擬在跑）：mlx-whisper medium 中位數 0.31 秒，95% 在 0.33 秒內。沒有 Apple 晶片的電腦，預設改用 CPU 跑的 faster-whisper **small**：同一台電腦的 CPU 上中位數 0.98 秒，95% 在 1.05 秒內（medium 要 2.8 秒，對說一句指令來說太慢）。small 稍微不準一點（安靜的房間、同一批測試句：繁中 80.0%、English 98.6%、日本語 91.4%、Español 92.9%、简中 85.7%、한국어 92.9%）。CPU 比較慢的電腦會更久。
