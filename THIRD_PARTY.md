# Third-party material and licences

duckmind's own code is licensed under Apache-2.0 (see [LICENSE](LICENSE)).
Attributions for the bundled third-party material are in [NOTICE](NOTICE).

"Bundled" below means the file is tracked in this repository. "Not bundled" means
the user fetches it from its upstream source (most of it through `python -m duckmind.setup_cmd`),
or it is not used at all.

This page is an engineer's reading of the licences, not legal advice. The licences
were checked against their primary sources on 2026-10-29.

## Read this first

- **The Microduck 3D meshes are CC BY-NC-SA 4.0 and are not bundled.**
  The `.stl` files in Pollen Robotics' `microduck_rl`
  (`src/mjlab_microduck/robot/microduck/assets/*.stl` and
  `src/mjlab_microduck/robot/xl330_test_bench/assets/*.stl`) are licensed under
  [Creative Commons Attribution-NonCommercial-ShareAlike 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/legalcode)
  (upstream `LICENSE-MODELS.md`). That licence is not compatible with Apache-2.0, so
  the meshes must never be put in this repository, a wheel, an sdist or a Docker
  image. `python -m duckmind.setup_cmd` prints the licence and downloads the `microduck_rl`
  checkout only after the user types "yes" (or passes `--accept-mesh-licence`).
  The simulator page shows the attribution in all six languages.
- **The screenshots, clips and README banners in `docs/media/` are CC BY-NC-SA 4.0, not
  Apache-2.0.** They are renders of the simulator, so they show the Microduck 3D model
  (Pollen Robotics, CC BY-NC-SA 4.0). They are shared under the same licence, with
  attribution, for non-commercial use only. See [docs/media/README.md](docs/media/README.md).
- **The MJCF robot descriptions are Apache-2.0.** Upstream `LICENSE-MODELS.md` says:
  "Everything else in this repository, including the MJCF robot descriptions
  (`.xml`), the export configs (`config_mjcf_*.json`, `config.json`) and the Onshape
  part metadata (`.part`), is licensed under the Apache License 2.0." That file was
  added upstream in commit `7cc1961` (2026-10-09), after the commit duckmind pins
  (`cb70b79`, 2026-09-14). The README at the pinned commit only says "3D model files
  are licensed under Creative Commons BY-SA-NC". duckmind bundles none of these
  files; `world/apartment.py` stores two sha256 values only.
- **Hugging Face policies that state no licence are not redistributed.** Eight
  community policy repositories have no licence in their metadata (list below).
  They are not copied here, not forwarded, and not used as a starting point for
  published results.
- **Test voices are Qwen3-TTS output (Apache-2.0).** The 13 clips in
  `tests/fixtures/voice/*.wav` are made locally with
  `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign` from written voice descriptions. No voice is
  cloned from a real person, and no non-commercial voice model is used.
- **Gemini outputs come under Google's terms, not a licence.** See the Gemini row and
  [PRIVACY.md](PRIVACY.md).

## Python dependencies

These are installed by `uv` or `pip`; none of them is bundled.

- **Required and `dev` dependencies (the 48 packages in `uv.lock` before the extras):**
  all permissive: MIT, BSD, Apache-2.0, PSF, ISC, MIT-0, 0BSD, Zlib and CC0 parts
  (in `numpy`). Weak copyleft, used unmodified: `certifi` and `pathspec` (MPL-2.0).
  `colorama` (BSD-3-Clause) is Windows only. No GPL.
- **`tag-fallback` extra:** `opencv-python-headless` is Apache-2.0; its wheel ships
  FFmpeg, which is LGPL.
- **`sim` extra:** MuJoCo (Apache-2.0) and Pillow (MIT-CMU).
- **`train` extra:** mostly Apache-2.0, BSD and MIT. Points to know:
  - mjlab 1.3.0 requires `torchrunx`, which is **GPL-3.0**, and through it
    `paramiko` (LGPL-2.1).
  - `imageio-ffmpeg` ships an FFmpeg binary.
  - On Linux, PyTorch pulls NVIDIA CUDA wheels under NVIDIA's own licence terms.
  - `tqdm` and `orjson` include MPL-2.0 parts.
  - `rustypot` (a Pollen Robotics package required by `mjlab_microduck`) states no
    licence in its metadata.

  duckmind does not import or ship any of these, so they do not change duckmind's
  Apache-2.0 licence. A Docker image or other bundle that includes the `train`
  extra would carry GPL and LGPL packages and must offer their source.
- **`kws` extra:** Apache-2.0 (`qwen-tts`, `transformers`, `accelerate`, `gradio`),
  MIT (`pypinyin`), BSD-3-Clause (`soundfile`, which ships libsndfile under LGPL),
  ISC (`librosa`); `soxr` is LGPL-2.1-or-later.
